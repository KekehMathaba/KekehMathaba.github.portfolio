# Kekeletso Mathaba — Professional Portfolio

A responsive, five-page portfolio for **IT Professional Practice ITPP5112**. It uses plain HTML, CSS and JavaScript, so no build tools or package installation are required.

## Preview locally

Open `index.html` in a browser. The site also works from a small local web server if preferred.

## Publish with GitHub Pages

1. Create a public GitHub repository. For a personal site, name it `your-username.github.io`; alternatively use any repository name for a project site.
2. Add all files and folders in this project to the repository, keeping `assets/` beside the HTML files.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish, then open the URL shown in the Pages settings. Confirm the five pages and portrait load on desktop and mobile.

## Before submitting

- The GitHub and LinkedIn links on `contact.html` point to the profiles supplied for this portfolio.
- The Projects page links to the Chat App and Service Request Tracking App repositories. Add verified technologies, features and screenshots as desired.
- Only publish assessment material that is approved for public release. Do not add passwords, API keys or private information.
- The contact email is displayed publicly to meet the assignment requirement.
